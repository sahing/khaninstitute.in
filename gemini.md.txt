# Website Build Prompt — Khan Institute

---

Build a professional, modern, responsive **4-page website** for "Khan Institute," a vocational/skills training institute in Dholahat, South 24 Parganas, India. Use **plain HTML5, CSS3, and vanilla JavaScript only** — no frameworks, no build tools, no CMS. The site must have excellent, professional UI/UX: clean layout, strong visual hierarchy, generous whitespace, smooth micro-interactions, and a trustworthy, modern educational-institute feel (not generic template-looking).

## 1. Design Direction

- **Style:** Clean, modern, professional, welcoming — think a well-designed local education/training center site, not corporate-cold and not cluttered.
- **Color palette:** Choose a cohesive palette built around 1 primary brand color (something warm/trustworthy — e.g., deep blue, teal, or maroon works well for an Indian educational institute) + 1 accent color + neutral grays. Avoid pure black/white — use soft off-white backgrounds and dark charcoal text.
- **Typography:** Pair a clean sans-serif for body text with a slightly bolder sans-serif or friendly display font for headings. Must support both **Latin and Bengali script** clearly (e.g., pair a font like "Poppins" or "Inter" for English with "Noto Sans Bengali" or "Hind Siliguri" for Bengali, loaded via Google Fonts).
- **Visual details:** Rounded corners on cards/buttons, subtle shadows for depth, consistent spacing scale (8px grid), smooth hover/transition states (200–300ms ease), icons where useful (use a free icon set like Lucide or Feather via inline SVG — no paid icon fonts).
- **Imagery:** Use clearly labeled placeholder image blocks (with descriptive alt text and a placeholder background) for: hero banner, gallery photos, course icons — client will replace with real photos later.
- **Tone:** Warm, encouraging, community-focused — this institute serves local students learning practical skills.

## 2. Technical Requirements

- Pure **HTML/CSS/JS**, mobile-first responsive design (must look great on phones — most visitors will be on mobile)
- Sticky/fixed header navigation with smooth scroll or clear page links
- Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, proper heading hierarchy)
- Accessible: sufficient color contrast, alt text on all images, visible focus states, readable font sizes (min 16px body text)
- Fast-loading: no unnecessary dependencies; only load Google Fonts + optional small icon SVGs
- Cross-browser: modern Chrome, Safari, Firefox, Edge, and mobile browsers
- Clean, commented, well-organized code across separate files

## 3. Bilingual Requirement — English + Bengali

- Add a **language toggle** (EN | বাং) in the header, visible and easy to tap on every page
- Clicking it switches ALL visible text on the current page instantly (no reload) between English and Bengali
- Implement via a JavaScript translation object (key → {en, bn} pairs) applied to elements via `data-i18n` attributes, plus a small script that swaps `textContent` based on the selected language, remembers the choice (in-memory for this session is fine)
- Include reasonable Bengali translations for all UI text, nav labels, headings, course names, form labels, and footer content
- Bengali font must render correctly and legibly (use "Noto Sans Bengali" or "Hind Siliguri" from Google Fonts)
